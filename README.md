이 웹사이트는 사용자의 정보를 바탕으로 사용자에게 어울리는 직업을 추천해주는 웹사이트입니다.

작동에 고용24 API Key가 필요하며, 나이, 학력, 관심분야는 필수 입력사항입니다.
추가적으로 OpenAI API Key 입력 시 추천 직업에 대한 AI 직무 요약과 추천 이유에 대한 부가적인 설명을 제공받을 수 있습니다.
성격(MBTI)과 전공은 선택 입력사항으로, 입력 시 더 사용자와 맞는 직업을 추천받을 수 있습니다.

활용한 기술 스택은 다음과 같습니다:

Python 3, Streamlit, Work24 OpenAPI, OpenAI API, requests, xml.etree.ElementTree, st.cache_data
